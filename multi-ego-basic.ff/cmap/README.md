Populations in % : target / sampled run / **with the map** (reweighted frames) ± block SE. Basins: aR phi<0, -120<psi<50; PII -100<=phi<0 and beta phi<-100 (psi outside the aR band); aL phi>=0, -90<psi<90. dG(aL-aR) in kJ/mol.

Held-out check: a map fitted on one half of the frames, applied to the other half, both ways; it estimates what a new simulation with the map will show. built with pdb2gmx + multi-eGO `--backbone cmap`, mg matrix; its unbiased
populations match the runs the maps were fitted to, e.g. Thr aR/PII/beta
20.4/21.3/57.2 vs 18.7/21.7/58.4 %). All 20 were stable; without maps the
same dipeptides run at 294-297 K. Populations in % (dynamics ± block SE /
target). 5 ns is short: the aR <-> beta/PII exchange is slow (Thr, Ile, Val
cross only a few times: the target's bridge region near psi 75 holds only
0.04-0.13 %, which the maps reproduce), so these runs check stability and
temperature more than populations.
